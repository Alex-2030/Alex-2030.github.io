# Alex-2030.github.io

Personal portfolio of Ahmed Salama: an interactive, space-themed "logbook" built with plain HTML, CSS and JavaScript (no frameworks, no build step).

**Live:** https://alex-2030.github.io

## Features
- Warp-speed transitions between sections, drawn on a single canvas starfield
- Works on phones: full-screen panels, large touch targets, safe-area aware, and the Back button moves between sections
- Respects reduced-motion settings and pauses animation when the tab is hidden
- Sections: About, Skills, Certificates (with credential links), Projects (with GitHub links), Contact

## Run locally
Open `index.html` in a browser, or serve the folder with `python -m http.server`.
